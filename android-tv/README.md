# SingShot TV Android App

This is a lightweight Android/Google TV wrapper for the live SingShot wall:

https://singshot-london-karaoke.genbarom.chatgpt.site/wall

## Build in Android Studio

1. Open Android Studio.
2. Choose **Open** and select this `android-tv` folder.
3. Let Android Studio install or sync the Android Gradle Plugin if prompted.
4. Build with **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Install the APK on Google TV.

The app starts full-screen, hides system UI, keeps the screen awake, and reloads the wall if Back is pressed.
